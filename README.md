# fun-processing-projects
A collection of random experiments I made using Processing throughout the years

## List of files:
- string.pde : A simple simulation of a wave propagating on different materials, reflecting and being transmitted while doing so
- circly_stuff.pde : Press the arrow keys to generate fun geometric shapes of different periods
- central_limit_theorem.pde : A visualisation of the central limit theorem
- mand2.pde : Visualisation of the mandelbrot set (you can find some examples )
- spring.pde : Quick demo of a "spiderman-like" movement system for a platformer game
- tiling_gradients.pde : Generates a tiled pattern on a triangular grid. I used this for graphics design purposes
- waves.pde : rendering of the diffraction pattern of a rectangular slit
